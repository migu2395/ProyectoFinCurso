# Proyecto Fin de Curso – Infraestructura de Red Virtualizada

Este repositorio contiene la documentación técnica y la configuración de la infraestructura de red del proyecto.

## Tecnologías utilizadas
- OPNsense
- Unbound
- DNSmasq
- Suricata
- Tailscale
- Proxmox VE
- Docker / Docker Compose
- Proxmox Container Toolkit
- Nginx Proxy Manager
- Prometheus + Grafana
- Jellyfin
- Termix
- Portainer

## Configuraciones
Las configuraciones de cada sistema operativo, servicio, aplicación, etc, se encuentran en la carpeta con su nombre.
